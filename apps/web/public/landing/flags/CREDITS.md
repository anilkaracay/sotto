# Flag credits

The thirteen flags on the landing are the square flags of the flag-icons project, https://github.com/lipis/flag-icons, version 7.5.0 (the npm package `flag-icons`, `flags/1x1/`), unmodified. Each file here has the same SHA-256 as its file in the package's tarball, `https://registry.npmjs.org/flag-icons/-/flag-icons-7.5.0.tgz` (SHA-256 `c0b80bf0e08006a60f56621d6bc49f8c7131f4d1fef6737a165a673431f4b518`), compared on 2026-10-07.

Files: `ar.svg`, `au.svg`, `br.svg`, `ca.svg`, `de.svg`, `gb.svg`, `id.svg`, `in.svg`, `jp.svg`, `ke.svg`, `ng.svg`, `ph.svg`, `tr.svg`.
